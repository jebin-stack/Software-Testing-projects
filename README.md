# E-Commerce Website Testing Project

## Project Overview
This project contains manual and automation testing for an e-commerce website using Selenium, TestNG, and Maven.

## Tools & Technologies
- Java 11
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Extent Reports

## Project Structure
- Manual testing documents (Test Plan, RTM, Test Cases, Test Summary)
- Selenium automation framework (Page Object Model)
- TestNG XML configuration

## How to Run Automation Tests
1. Clone the repository
2. Open the automation folder in Eclipse
3. Run tests using:
   - testng.xml
   - Maven: `mvn test`
